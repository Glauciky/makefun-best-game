Starfall Salvage is a wave-based arena survival game. Pilot a salvage drone through a drifting asteroid field, collect star shards, outfly void wisps, and choose an upgrade after every wave. Survive all ten waves and defeat the Void Warden to clear the sector.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
